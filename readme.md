# Network Intrusion Detection with Explainable ML

## Overview
A machine learning-based network intrusion detection system designed to identify suspicious network traffic, classify known attack types, and explain model predictions.

## Objectives
- Detect anomalous network traffic.
- Classify known network attacks.
- Explain predictions using SHAP.
- Evaluate false positives and false negatives.
- Provide a dashboard for inspecting detection results.

## Planned Architecture
1. Data preprocessing and exploratory analysis
2. Unsupervised anomaly detection
3. Supervised attack classification
4. Prediction fusion
5. Explainability and evaluation
6. Dashboard integration

## Technology Stack
- Python
- scikit-learn
- XGBoost
- SHAP
- Pandas and NumPy
- Streamlit

## Dataset
Planned dataset: CICIDS2017.
